# CH341A Tool - Delphi/Pascal Port

## Описание проекта

Это порт утилиты CH341A-tool из C++ Builder в Delphi/Pascal для работы в RAD Studio 2010.

## Структура проекта

```
CH341A_Delphi/
├── CH341A_Tool.dpr          # Главный файл проекта
├── CH341A_Tool.dproj        # Файл проекта RAD Studio
├── README_PORTING.md        # Этот файл
├── Source/                  # Основные модули
│   ├── FormMain.pas         # Главная форма
│   ├── Settings.pas         # Управление настройками
│   └── Log.pas              # Система логирования
├── Forms/                   # Формы приложения
│   ├── FormAbout.pas        # Форма "О программе"
│   ├── FormSettings.pas     # Форма настроек
│   └── LogUnit.pas          # Форма просмотра лога
├── Tools/                   # Инструменты (требуют реализации)
│   ├── I2C/
│   ├── SPI/
│   ├── GPIO/
│   └── MDIO/
└── Lib/                     # Библиотеки
    └── CH341DLL.pas         # Обертка для CH341DLL.DLL
```

## Требования

1. **RAD Studio 2010** или совместимая версия Delphi
2. **CH341DLL.DLL** - оригинальная библиотека из проекта CH341A-tool
3. Драйверы CH341A установлены в системе

## Установка

### Шаг 1: Подготовка DLL
Скопируйте `CH341DLL.DLL` из оригинального проекта в папку с исполняемым файлом:
```
<папка_проекта>/Win32/Debug/CH341DLL.DLL
<папка_проекта>/Win32/Release/CH341DLL.DLL
```

### Шаг 2: Открытие проекта
1. Запустите RAD Studio 2010
2. Откройте файл `CH341A_Tool.dproj`
3. Соберите проект (F9)

### Шаг 3: Настройка путей (если требуется)
Убедитесь, что пути к исходным файлам указаны правильно в настройках проекта.

## Отличия от оригинала

### Синтаксические различия C++ Builder → Delphi

| C++ Builder | Delphi/Pascal |
|-------------|---------------|
| `#include` | `uses` |
| `void __fastcall` | `procedure` |
| `int __fastcall` | `function: Integer` |
| `__declspec(dllexport)` | `stdcall` |
| `UnicodeString` | `string` |
| `DynamicArray<T>` | `array of T` |
| `try { } catch (...) { }` | `try except end` |
| `for (int i=0; i<n; i++)` | `for i := 0 to n-1 do` |

### Работа с памятью
- В Delphi управление памятью автоматическое для объектов
- Для массивов используйте `SetLength()`
- Освобождайте объекты в деструкторах или блоках `finally`

### Работа с DLL
```pascal
// Загрузка DLL
if not LoadCH341DLL then
  ShowMessage('Ошибка загрузки DLL');

// Вызов функции
DeviceIndex := CH341OpenDevice();

// Выгрузка DLL
UnloadCH341DLL;
```

## Требуется реализовать

❌ **Основной класс работы с устройством**
- Инициализация устройства
- Чтение/запись данных
- Обработка ошибок
- Асинхронные операции

❌ **Формы инструментов** (~60 форм)
- I2C устройства (EEPROM, RTC, ADC, DAC и др.)
- SPI устройства (Flash EEPROM, MCU и др.)
- GPIO тестер
- MDIO инструменты

❌ **DFM файлы**
- DFM файлы создаются автоматически при сохранении форм в IDE
- Необходимо открыть каждую форму в дизайнере и сохранить

❌ **Дополнительные библиотеки**
- JSON парсер (рекомендуется SuperObject)
- Поддержка скинов (необязательно)

## Пример использования CH341DLL

```pascal
uses CH341DLL;

// Подключение устройства
if LoadCH341DLL then
begin
  DeviceIndex := CH341OpenDevice();
  if DeviceIndex >= 0 then
  begin
    // Устройство подключено
    
    // Пример I2C чтения
    var Buffer: array[0..255] of Byte;
    if CH341ReadI2C(DeviceIndex, $50, $00, 16, @Buffer) then
    begin
      // Данные прочитаны успешно
    end;
    
    // Отключение
    CH341CloseDevice(DeviceIndex);
  end;
  
  UnloadCH341DLL;
end;
```
